# 可选界面风格

在「设置 → 外观 → 界面风格」选择预览卡片即可即时应用。

| 风格 | 界面特点 | 推荐色调 |
| --- | --- | --- |
| 经典纸感 | 保留原版暖白纸面和细边框 | 青碧 |
| 晨光工作室 | 奶油暖色、宋体展示标题、柔和卡片与暖色侧栏 | 琥珀 |
| 极光浮岛 | 冷色柔光、独立页头、悬浮侧栏、圆润卡片 | 靛蓝 |
| 精密面板 | 清晰线框、紧凑间距、小圆角与分区标线 | 湛蓝 |

所有风格支持浅色、深色和跟随系统。单独切换风格保留已有配色、明暗模式和背景图片；整套搭配才会同时应用推荐配置。分类、状态颜色保持原有语义。选择「经典纸感」即可恢复原版风格。

偏好仅保存在本机 `xk.theme.v1`，增加 `style` 字段，不进入加密业务数据或云同步。旧设置没有此字段时使用经典纸感；未知风格、模式与强调色会回退到有效值。页面初始化与 Vue store 采用一致的首屏属性规则。

## 实现

- `src/stores/theme.ts`：四套风格元信息、切换、持久化、系统明暗响应。
- `src/components/settings/InterfaceStylePicker.vue`：可通过键盘操作的预览选择卡，使用 `aria-pressed` 表达选中状态。
- `src/interface-styles.css`：明暗基座、卡片/导航/标题/间距与预览 Token。
- `src/style.css`：Tailwind 圆角映射至运行时 Token，原版辅助文字对比度调整。
- `design-system/MASTER.md`：各风格允许的颜色、圆角、投影和渐变范围。

## 验证

执行 `npm run build`，然后运行预览服务；通过 `QA_URL` 指定地址，执行 `node scripts/verify-interface-styles.mjs`。需要可用的 Playwright 与 Microsoft Edge，可通过 `PLAYWRIGHT_MODULE` 指定本机 Playwright 模块路径。脚本使用隔离浏览器上下文创建测试保险库，不读取真实用户保险库。

覆盖四套风格 × 两种明暗模式、375/768/1024/1440 四档宽度、辅助文字与主要表面对比度、手机设置、键盘操作、系统明暗切换、刷新恢复、自选色调保留、切回原版、未知值回退与业务数据保留。截图和报告输出至 `.visual-qa/interface-styles/`。浏览器验证不代表 Android 或 Windows 安装包的真机验收；已安装客户端需要重新打包更新。
