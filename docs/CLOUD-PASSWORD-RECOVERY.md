# 云账号改密与找回（1.1.7）

网页、Android 和 Windows 使用相同流程。

## 使用

1. 登录后打开「设置 → 安全 → 云账号安全」。选择「设置云恢复密钥」，验证当前云密码，保存完整密钥并确认。只需设置一次，各端通用；重新生成会让旧云恢复密钥失效。
2. 修改密码：同一区域选择「修改云密码」，输入当前密码和两次新密码，点击「确认修改云密码」。本机解锁密码同时更新。
3. 忘记密码：新设备首页点「忘记云账号密码？」；已加入设备锁屏点「忘记密码？」。输入云账号、提前保存的云恢复密钥和新密码，点击「重设密码并登录」。数据会恢复并继续同步，无需传递连接文件或保险库文件。

改密和找回需要联网。操作成功后所有旧云同步令牌失效，其他设备用新密码登录一次即可恢复同步并更新本机解锁密码。尚未联网的旧设备仍可能用上一次成功登录的密码离线解锁；无法远程撤回已下载的明文或密钥。生物识别凭据在本机密码封装更新后清除，需要重新开启。

未启用云恢复、也没有有效密码时，不能直接恢复云账号。请从仍能访问的设备导出数据备份。旧版本机恢复密钥不等于云恢复密钥。云恢复密钥不是数据备份；它需要服务器保留相应恢复信息和密文数据。不要把唯一恢复密钥只保存在这个应用内。

本机已有未上传的数据不会被云端初始化信封覆盖。使用新云密码登录时先验证保险库身份、解密本机现有信封，再原子替换密码封装和加密连接凭据。待上传记录、冲突、附件及其他加密配置保留。旧版独立本机账户继续保留原有本地恢复流程。

## 协议与错误处理

- 服务端新增 cloud_security 表，现有云账号自动初始化 revision=1，不启用任何默认恢复密钥。
- 恢复密钥为客户端生成的 256 位随机秘密。客户端 AES-GCM 包装数据密钥，认证值通过独立 recovery-auth 域生成，服务端保存认证值摘要与密文恢复封装，不保存原始恢复密钥或密码。
- 密码变更只重新包装同一数据密钥，不重新生成保险库或业务密钥。服务端验证 vaultId、keyId、原始初始化密文及时间戳保持一致。
- 修改和恢复要求当前密码认证值或云恢复认证值，以及最新 revision。密码校验值、封装、版本递增、旧会话撤销在同一个 SQLite 事务内提交。过期并发修改返回 409。
- 同步接口在收完请求体后重新校验会话，防止已被撤销的旧会话在请求体延迟发送后继续写入。
- 超时等未知结果不自动重试写入，界面提示先使用新密码登录确认。服务器改密成功但本机写入失败时，不清空本机数据，可用新密码重新登录完成。
- 页面关闭、锁定、账号变化后不继续发起新的改密或恢复提交；已发送的服务器事务仍可能完成。
