# 云账号与跨设备同步（1.1.7）

1.1.7 已支持云账号改密和恢复密钥找回，详见 [CLOUD-PASSWORD-RECOVERY.md](CLOUD-PASSWORD-RECOVERY.md)。

首次使用在首页选择「首次使用，创建云账号」，设置账号和密码。其他设备安装 1.1.7 或打开 https://111.91.19.235 后，直接用同一账号密码登录。无需导入连接文件、保险库文件或输入令牌。

账号为 3–40 位英文、数字、点、横线或下划线，不区分大小写。注册后请在「设置 → 安全 → 云账号安全」保存云恢复密钥。此处可修改云密码；登录页「忘记云账号密码？」可用该密钥设置新密码。旧版本机恢复密钥不适用。

首次登录必须联网。之后输入本机密码可离线解锁；联网、回到前台或修改内容后自动同步，前台周期为 45–60 秒。系统关闭或挂起应用时不保证后台同步。附件默认按需下载，完整离线使用前可在同步设置选择全部下载。

旧本机账户不自动改成云账号，也不自动清除。用户确认目前没有需保留的数据；若旧版已经创建空的本机账户，可在锁屏「忘记密码 → 无法恢复？其他选项」中自行清除本机数据后进入新入口。已有真实数据时不要清除，应先导出备份。

## 实现与边界

- 账号密码在客户端通过 PBKDF2-SHA256（600000 次，独立认证域及规范化账号）生成认证值。HTTPS 只传认证值，不传原始密码；服务端仅保存其 SHA256 校验值。
- 业务数据密钥仍为随机 AES-256 密钥，由原有 Argon2id + AES-GCM 密码封装保护。服务器保存封装和加密的空白初始化信封，不能直接获得业务密钥。
- 新设备验证密码、解开密钥并拉取/校验历史密文记录后，才事务写入本机保险库和加密连接凭据。没有文件传递，未登录无法读取初始化信封。
- SQLite 增量增加 cloud_accounts、cloud_sessions 表。每次登录签发独立随机会话令牌，只保存摘要；保留最近 32 次登录的令牌，不按时间自动过期。旧设备被淘汰或移除配置后，可在同步设置输入云账号密码重新连接。
- 云账号仅能访问注册时绑定的保险库。旧管理员令牌模式继续兼容。认证接口全局最多突发 20 次、每 6 秒恢复一次额度；私人服务器最多 16 个云账号，沿用数据库 2 GiB 与附件配额。没有开放注册邮件验证或管理员账号管理界面。
- 不向安装包嵌入任何共享令牌、密码或 SSH 密钥。客户端只预设公开服务器地址。
- 1.1.7 的云账号设置统一修改云密码及当前设备密码；其他设备联网用新密码登录后更新本机封装。旧版独立本机账户保持本地改密路径。
