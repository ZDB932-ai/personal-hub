# 非 AI 优化与当前验收边界

本轮依据 [开源调研](OPEN-SOURCE-RESEARCH-2026-09-20.md) 实施，按用户要求暂不做 AI 远程功能。调研中的远期建议不是已完成功能。本页描述本轮增量；设备密钥、逐条同步服务、原生导出等基础能力见对应专题文档。

## 使用入口

| 能力 | 入口与行为 |
| --- | --- |
| 全局搜索与收集 | 顶栏搜索或 Ctrl/Cmd+K；检索任务、备忘录、资料、项目、账号的公开描述字段，快捷新建或上传；密码、TOTP 密钥、账号备注不参与搜索 |
| 任务来源关联 | 编辑任务时关联备忘录、资料、项目；备忘录转任务保留来源；被删除的引用显示不可用 |
| 时间容量 | 任务与周计划填写预计分钟；每日计划设置每日可用时间；周排期结合已有负载、精力与偏好，不强行填入放不下的任务；确认时校验预览是否过时 |
| 回收站与历史 | 设置 → 备份；恢复为新副本，保留当前条目；修改历史记录已保存的实体内容，不是逐个键盘输入的历史 |
| 字段冲突 | 设置 → 同步；主动展开两边差异；任务和备忘录允许保留两个副本 |
| 附件下载策略 | 设置 → 同步 → 逐条同步；全部下载或打开时下载；按需模式的列表缩略图不会主动下载缺失文件 |
| 资料正文搜索 | 资料卡手动提取正文；文本与含文字 PDF 支持当前解锁会话内搜索；锁定即清空索引 |

## 数据与同步行为

- 前台解锁且在线时约每 45–60 秒请求逐条同步；切回前台也触发。锁定、暂停或断开后停止周期请求。
- 已校验附件在同一连接与密钥下不随空拉取反复全量解密；附件变化、重新连接或手动同步重新检查。
- 下载分块缓存只存密文，并验证分块哈希与最终 GCM 认证。缓存最多 64 块；被淘汰的块需重新获取，因此不是无限期离线缓存。成功下载后清理相应缓存。
- 修改历史与删除记录在加密业务信封中保存，按保存时的保留策略限制为最近 30 天；删除记录最多 200 条 / 2 MiB，修改历史另限 100 条 / 1 MiB（单项最多 20 个版本，继续线索的连续编辑按 5 分钟合并）。逐条同步不传播历史列表，完整备份包含历史及其附件；启用前已删除内容无法找回。
- 删除资料保留加密文件，供历史恢复使用。清空历史不会自动回收附件空间；附件垃圾回收尚未实现。
- 已保存的数据快照写入 `schemaVersion: 1`；读取兼容无版本旧数据，检查已知字段类型和重复标识，保留未知字段。它不是覆盖所有业务约束的完整模式验证器。
- 正文提取限制单文件 10 MiB、PDF 前 200 页、最多 10 万字符。尚无 OCR、Office 全文索引或持久化全文索引。提取在本机完成，不上传正文索引。

## 验证方式

基础检查：`npm run build`、`npm run test -- --maxWorkers=2`、`npm run sync:typecheck`。CI 已补入服务端类型检查。

浏览器脚本使用临时独立存储与合成数据，预览地址默认 `http://127.0.0.1:4183`：

```powershell
npm run preview -- --host 127.0.0.1 --port 4183 --strictPort
node scripts/verify-hub-ui.mjs
node scripts/verify-sync-ui.mjs
node scripts/verify-backup-ui.mjs
```

脚本需要可解析的 Playwright 模块和 Edge；可用 `PHUB_PLAYWRIGHT_MODULE` 指向已安装的 Playwright，`PHUB_VERIFY_URL` 更换预览地址。它们目前不是 CI 中固定浏览器版本的自动验收。报告与截图输出到 `.visual-qa/`。

本轮没有重新打包或验收 Windows 安装包、Android APK，也未执行 HTTPS 公网真机测试。浏览器的双设备隔离存储测试不能替代这些验收。

2026-09-20 验证：23 个测试文件、155 项测试通过；构建与服务端类型检查通过。隔离浏览器验证了搜索/收集/关联/历史恢复/容量编辑/锁定清理正文，以及真实 HTTP 的前台静置拉取、按需跨分块附件下载、暂停恢复、服务重启重试、字段冲突、自动重连与移除配置。不同主密码的备份恢复和附件逐字节比较通过。报告目录见 `.visual-qa/sync-1789891154720`、`.visual-qa/backup-1789891290743`；搜索布局报告随脚本生成。
