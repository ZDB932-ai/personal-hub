- 四组场景：日光工作室、深海指挥台、暮色手帐、云端花园，联动界面、明暗、强调色、壁纸，可撤销至上一次应用前。

- 十张离线壁纸：四张原创 + 六张经典，支持分类浏览、桌面/手机构图预览和放大预览。
- 自动遮罩（浅色 30%、深色 48%）、手动 0–90%、阅读衬底、0–16px 柔化、100–150% 缩放、水平和垂直位置、重置调节。
- 自定义图片支持 JPG/PNG/WebP/AVIF，8MB、3200 万像素以内，先解码再提交；切换内置后仍保留可选自定义图。删除失败保留显示，删除需确认。
- 仅本机保存；锁屏不展示壁纸。旧版 dim 值迁移为手动遮罩，不改变用户原来的设置。

自定义图片由 IndexedDB 持有，object URL 在替换/删除时回收，调节参数不重复读库或创建 URL；异步读取通过 revision 防止迟到结果覆盖新图片。图片写入须等事务完成才报告成功。

## 原创素材

采用内置 imagegen 生成，原件在 `assets/wallpaper-originals/`。提示词的共同要求：16:9、全幅不透明、左侧和中央留白供界面使用、无文字标志、无设备或 UI 模型。

- solar：SOLAR ATELIER，杏橙/珊瑚/朱红的缎面陶瓷折带沿右侧和下沿展开，暖瓷色基座、日光、柔软长阴影。
- abyss：ABYSSAL PRISM，钴蓝透明玻璃带沿右侧与底部弯曲，克制青色折射与紫色点缀，深海蓝留白、真实焦散光。
- dunes：DUNE AFTERGLOW，玫瑰/陶土/杏色沙丘，朦胧紫色远山，桃色与薰衣草色暮空，摄影感宽阔风景，无人无建筑。
- garden：CLOUD GARDEN，兰紫与冰蓝透明玻璃花瓣在右侧展开，薄荷与珠光高光、淡紫云光、通透植物抽象。

`scripts/export-wallpapers.ps1` 通过 System.Drawing 输出全尺寸 JPEG（质量 88）与 420px 缩略图（质量 82）；发布资源含原有六张合计约 875 KiB，不依赖外部图片服务。
