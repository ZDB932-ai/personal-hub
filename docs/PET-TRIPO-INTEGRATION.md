## 动作契约

每个语义动作独立记录真实 clip 名、Tripo 预设名、任务 ID、循环策略、原地状态和播放速度。不依赖统一骨骼命名；不将奶龙专用姿态叠加到其他骨架。

- 待机和移动循环播放，互动动作单次播放后返回实际待机；没有待机时恢复原始姿态，而不是把鼓掌无限循环当待机。
- 巡游要求已核验的原地循环 walk / run；没有移动能力的角色禁止自主巡游，不用窗口滑行掩盖缺失动作。
- 每个角色只提供实际支持的互动。不存在 eat / sleep / wave 时不宣称播放成功，也不使用无关动作冒充。
- `inPlace` 是导出验证后填写的声明，不是播放控制器自动证明的结果。
- 减少动态效果时暂停播放；后台暂停、恢复及 GPU 资源释放仍需渲染层实现和验收。
