# 界面优化 · 2026-09-20

本轮沿用暖白纸感、语义主题色和无装饰渐变的设计系统，重点改善内容层级、跨模块入口与可读性。

## 改动

- 总览新增工作台：今日待办最多展示五项，优先展示重点；显示完成数、待办预计分钟与可用时间差，点击进入原任务编辑器。
- 快捷记录集中提供新建任务、备忘录和全局搜索；最近内容展示备忘录、资料及项目，点击打开原有查看或编辑窗口。
- 个人资料与账号信息保留在工作台下方；未添加账号时不再显示“密码强度良好”，个人资料说明改为准确的加密存储描述。
- 资料库与仓库收藏采用独立卡片和 16px 间隔，取消共享底板，避免条目少时出现填满空格的大块背景；选择态增加强调色边框。
- 全站标题限制为 24–30px，增加行高；移动端设置和锁定按钮触控区域扩大至 44px。
- 浅色辅助文字改为更深的语义色；深色六款强调色单独配置，按钮前景采用深色，改善链接和按钮文字的可读性。

## 验收边界

- `npm run build` 检查类型与生产打包。
- 使用独立端口、合成数据的组件验收页面，未解锁实际保险库。首页检查 375/768/1024/1440 宽度、深浅主题、有内容和空白状态；验证快捷任务入口，查看资料库单卡片布局。
- 验收截图位于 `.visual-qa/dashboard-design-light.png` 与 `.visual-qa/dashboard-design-dark.png`。截图含顶部测试工具栏，该工具栏不进入实际产品。
- 没有重新打包 Windows/Android，也没有修改 AI 远程功能。当前已运行的旧桌面程序不会自动加载这些源码改动。
