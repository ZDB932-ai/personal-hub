# 桌面奶龙玩偶

> 历史实现记录：下文包含早期程序化角色、旧速度和旧动作说明。2026-09-22 的当前版本使用 Tripo 模型与八段 Blender 动画，详见 [交接索引](PET-HANDOFF.md)。下文原生验收仅针对当时版本，不代表新版验收。

性格动作：菜单与网页提供“探头看看 / 开心转圈 / 害羞一下”。动作采用准备、展开、恢复的时间曲线，配合轻微整体伸缩、收手和半闭眼；转圈使用独立连续角度和平滑恢复，减少中断时回跳。自主动作每 18–42 秒选择一次，不连续重复，隐藏、休息、跑动、拖动和菜单展开时不触发，减少动态效果偏好下关闭自主表演。未新增嘴型，害羞仍是原有笑脸。

支撑脚位移补偿：桌面每次成功更新窗口位置后累计逻辑像素距离，以发布模型投影尺度和支撑期长度换算步态相位，替代仅按时间摆腿。速度改为 35 逻辑像素/秒，支撑期去除腿部旋转，保持后移速度与窗口平移对应。运行时自动朝向路线，停止后恢复用户旋转角度。理论支撑位移抵消已有测试；蒙皮权重、身体侧摆与转弯阶段仍可能产生残余滑动，不宣称完整 IK 锁地。

小跑精修：起步采用限加速度，屏幕边缘前减速，转向停顿 550ms；动画步频接收实际速度比例。步态区分 60% 支撑期与 40% 抬脚回摆期，脚部轻微平移结合小角度旋转，减少腹部拉扯；身体起伏改为平滑余弦，头部反向稳定、前臂和尾巴延迟跟随。仍为程序化蒙皮步态，尚非脚底接触求解或完整 IK 锁地。

本轮新增：互动菜单提供 −180° 至 180° 旋转滑块与恢复正面；网页另有左右 45° 按钮。挥手与舞蹈幅度提高，双臂与身体起伏更明显。

原生验收：90° 侧面与恢复正面已检查；开启小跑后截图窗口横坐标由 2102 变为 1472，后续姿势朝右，确认实际移动与往返转向。打开菜单后可点击停止，停止后两次截图位置保持 1661/988。前端和桌面编译、11 项动作与边界测试通过。多显示器与不同 DPI 的真机组合尚未逐一验收。

“开始自主走动”是会话内开关（默认关闭）。Windows 在当前显示器工作区域内水平往返，速度按 DPI 缩放；到边缘转向，鼠标移至角色、拖动、打开菜单、其他互动、休息或窗口隐藏时暂停，条件解除后恢复。循环串行执行位置更新并限制时间步长，卸载时停止。网页展示局部小跑预览，不移动浏览器窗口。当前是程序化小跑，脚掌锁地与复杂路线尚未实现。

入口：设置 → 玩偶。默认关闭；Windows Tauri 桌面端可开启悬浮窗。`?pet=1` 在网页中显示带操作按钮的互动预览。

## 角色与动作

角色从第一版 SVG 重做为 Three.js 实时 3D 模型：圆润头身、奶油色肚皮、绿色虹膜、短手脚、棕色趾甲与尾巴。角色比例参考第七印象的官方形象，模型为本项目程序化重建，并非官方动画模型。

- 目光跟随鼠标，随机眨眼、转眼，呼吸和尾巴轻摆。
- 摸头：准备、起跳、手臂展开、落地回弹、恢复站姿；不再永久循环整体蹦跳。
- 挠肚：身体局部回弹；重复触发保持当前运动速度，避免回到起始姿势。
- 喂食：手臂抬起、蛋糕移近嘴边、咀嚼、食物变小。
- 舞蹈：身体重心、头部、手臂、脚步按不同相位运动，动作渐入渐出。
- 挥手、小憩、点击唤醒、拖动时悬空姿态。
- Spring 采用小步积分，保持 30/60/144 fps 下一致的收敛；长时间暂停后限制时间步长。
- 不通过 Vue 每帧重绘；WebGL 模块按需加载，只有角色组件挂载才导入。窗口不可见或组件不在视区时暂停渲染，卸载时释放几何体、材质、纹理和上下文资源。
- 尊重系统减少动态效果偏好；WebGL 无法创建时使用静态参考图降级。

角色代码：`src/lib/pet/nailong3d.ts`；动作插值：`src/lib/pet/motion.ts`；组件：`src/components/DragonPet.vue`。

## 桌面行为

- 独立 280 × 340 透明、无边框、置顶窗口，不出现在任务栏。
- 按住身体移动超过 5 像素后，按屏幕鼠标位移和 DPI 更新窗口位置；合并连续位置请求；双击打开主窗口。
- 「最小化或关闭到托盘后继续显示」独立开关，也可在玩偶菜单切换「后台陪伴」。
- 设置写入 Tauri app_config_dir/desktop-pet.json，仅包含布尔偏好，不读写保险库。
- 每次启动放到主显示器工作区右下方；「找回玩偶位置」用于屏幕切换后恢复。暂不保存上次拖动位置。
- 任务提醒复用现有提醒引擎，仅发送无正文事件；需单独开启玩偶提醒。小憩期间不展示，锁定后停止新提醒。
- 托盘退出会结束整个应用。
- 透明窗口目前有固定矩形交互区域，不提供透明像素鼠标穿透。

# Tripo 模型接入（2026-09-21）

桌面贴图加载使用 GLTFLoader 插件将纹理加载器设置为 TextureLoader。默认 ImageBitmapLoader 会对内嵌纹理 Blob URL 发起 fetch，而桌面 CSP 的 connect-src 不允许 blob:；图片加载走已有 img-src blob:，无需扩大连接权限。颜色贴图缺失时拒绝灰模并进入静态回退。

当前 DragonPet 使用 `src/lib/pet/tripo3d.ts` 加载 `public/pets/nailong-tripo.glb`，保留 Tripo 修复版的网格和三张材质贴图。`scripts/rig-tripo.py` 从修复版 Blender 文件生成九骨骼蒙皮（含双前臂）、Blink 形态键与可编辑的 `nailong-rigged.blend`；原始用户文件保持不变。

动作包括鼠标跟随转头、轻微起伏、挥手、舞蹈、挠肚子、喂食道具与闭眼低头休息。每个动作独立弹簧淡入淡出，骨骼四元数平滑追踪目标，连续切换不会直接清零旧姿势。闲置时有轻微张望和间隔 3–7 秒的眨眼；减少动态效果设置关闭自动眨眼和张望。Blink 通过眼部局部形态键闭合，眼周褶皱仍可精修，尚无嘴型变化、手腕关节或行走动画；大幅肩部动作仍需精修权重。

本轮验证：npm run build 与桌面 custom-protocol 编译通过；pet/petMotion 共 8 项测试通过（包含中断动作淡出与休息唤醒）。原生窗口实际检查了闭眼休息和摸头恢复睁眼，颜色贴图正常。未将静态姿势截图视为全部动作流畅性验收。

`scripts/check-tripo-rig.py` 重新导入发布 GLB 并渲染静止、挥手、舞蹈姿势，用于检查导出后的蒙皮。构建与网页预览需另行验证，离线渲染不能替代运行验证。
