# 捂脸动作实验

实验工程：`assets/pet-models/tripo-fixed/nailong-cover-face-study.blend`。

动作时间线：第 1 帧待机、第 12 帧预备、第 30–46 帧双手遮住脸颊前方、第 64 帧露出脸、第 82 帧放下、第 108 帧回位。

当前未通过视觉验收。原蒙皮支持小幅挥手，但抬手到脸部所需的大旋转造成肘部折叠，整体平移则使肩臂连接出现长条拉伸。仅检验有限坐标或包围盒无法发现这一问题，必须查看渲染。

实验保留为独立文件，在线使用的 `nailong-animated.glb` 已恢复上一版正常动作。后续需要针对肩臂拓扑重新分配连续权重，并制作抬手姿态修正形态；验证左右侧面、半程和最大遮脸姿态后再发布。实验脚本单独输出研究工程，避免覆盖使用中的模型。
