# 同步体验 · 第六阶段

连接成功后，服务地址、令牌、vaultId/keyId 和服务器身份一起使用当前数据密钥 AES-GCM 加密，保存至 IndexedDB Repository 的 `xk.record-sync.secure`。没有在 localStorage 中保存令牌或明文地址。设备加入文件与业务备份不包含此本机连接凭据。

每次打开应用仍需要输入主密码解锁。解锁后自动解密配置、核对保险库范围和服务器身份、恢复同步；锁定或保险库维护期间立即停止后续同步处理。已发往服务端的操作可能仍完成，依靠持久化在途请求和幂等回执恢复。连接等待和保存配置使用会话代数及密钥检查，旧连接不能覆盖新会话。

网络异常期间保留配置。握手网络失败按指数退避重试，网络恢复或前台唤醒也会触发连接；令牌错误、服务器身份变化等错误不盲目循环重试。用户可重试保存的连接，或输入新的配置。同步服务和保险库范围变化仍不能复用旧游标。

“断开并移除配置”停止本次同步并事务删除凭据；不会删除服务器记录或本地业务数据。删除失败明确显示错误，本次会话保持暂停，需重试移除。锁定期间失败的删除可能导致下次刷新解锁恢复原连接，界面不会将失败报告为删除成功。

新增“暂停同步”：保留加密连接配置，立即停止后续调度并使旧会话失效，等待当前任务结束后显示“同步已暂停”。到达服务器的在途请求可能已经生效，恢复时按幂等协议处理。本窗口锁定再解锁仍保持手动暂停，刷新或重新启动则恢复默认自动连接。点击“恢复同步”重新读取原配置，无需重新输入令牌。生成含大量附件的设备加入文件前可先暂停，避免后台同步改变存储版本。

状态区显示正在连接、同步中、待上传、待处理冲突、失败及已同步。第七阶段加入附件后显示“已同步（记录与附件）”，表示本轮同步完成，不代表远端以后没有新修改。仍通过修改、回到前台和网络恢复触发，不是持续实时推送。

v3 改密只重封装数据密钥，因此已保存的连接可继续解密；密钥迁移的通用加密凭据列表和本机重置列表也包含新键。普通备份恢复保留目标设备的本机配置；其他保险库的连接范围校验失败会停止连接。

验证：本阶段 15 个测试文件共 126 项通过，前端生产构建及服务端类型检查通过。新增测试覆盖密文落盘、恢复、锁定期间连接返回、配置切换、维护暂停恢复、配置删除、服务器身份变化与删除失败。Edge 生产构建端到端验证通过双设备同步、断线恢复、离线冲突、刷新解锁自动连接和主动移除配置后不再自动连接，记录位于 `.visual-qa/sync-1789867576819/report.json`。旧的三端测试报告中“令牌不持久化”是第五阶段行为，第六阶段已改为密文持久化。

第七阶段后已更新 Android Debug APK 与 Windows release exe，完成真机重启回归：分别结束应用进程，重新打开并输入各自主密码后自动恢复连接，无需再次输入服务地址或令牌，业务数据与附件校验均通过。记录位于 `.visual-qa/native-1789869163049/report.json`。手机连接使用 USB 端口转发，不代表局域网或公网 HTTPS 验收。
