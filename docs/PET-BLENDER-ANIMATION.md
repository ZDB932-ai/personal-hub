# Blender 宠物动画工程

> 历史阶段记录：下文为最初五段动画工程。最新入口为 `nailong-expression-polish.blend`，包含八段动画，详见 [交接索引](PET-HANDOFF.md)。

本阶段当时的入口是 `assets/pet-models/tripo-fixed/nailong-animated.blend`，发布资源路径为 `public/pets/nailong-animated.glb`（该路径现已更新为最新版本）。原始 Tripo 文件、修复版与旧九骨骼工程均保留。

## 本轮完成

- 骨架由 9 根增至 17 根：加入胸部、颈部、双手掌、双脚掌、尾中段和尾尖，并将头、肩膀接入胸颈层级。
- 重新分配新增关节的连续蒙皮权重，导出每顶点最多四个影响，保持原贴图与 Blink 形态键。
- 在 Blender Action 中制作 Idle、Walk、Wave、Eat、Shy 五段关键帧动画，包含准备、主体和回位。关键帧由脚本写入，可在 Blender 中继续编辑曲线与姿势，网页无需重新生成这些曲线。
- Three.js 使用 AnimationMixer 播放 GLB 片段，以平滑权重混合动作。行走采样跟随实际移动距离；注视、拖拽以及尚未改为片段的舞蹈等保留程序叠加。
- 每帧保存和恢复动画基础姿势，避免注视增量累计扭曲；默认 Blink 归零，避免导出闭眼模型。

## Blender MCP

使用项目官方安装方式 `uvx mcp-for-blender install-addon` 安装，Codex 中注册 `blender`，启动命令为 `uvx mcp-for-blender`。来源：https://github.com/ahujasid/mcp-for-blender 。

`scripts/start-blender-pet.py` 启用插件并在 127.0.0.1:9876 启动服务。已经验证插件的 execute_code 可读取当前工程、骨骼与 Action，也可设置动画预览。当前会话通过插件的本地协议控制 Blender；新注册的 MCP 工具是否出现在后续会话，由客户端重新加载配置决定，不将配置成功等同于工具热加载成功。

## 复现与检查

0. `D:/Blender/blender.exe --background --python-exit-code 1 --python scripts/refine-pet-surface.py` 从保留的九骨骼原工程生成 `nailong-refined-rigged.blend`；动画生成器以此作为输入。
1. `D:/Blender/blender.exe --background --python scripts/animate-tripo.py` 生成工程与 GLB。
2. `D:/Blender/blender.exe --background --python scripts/check-animated-pet.py` 重新导入 GLB，采样蒙皮顶点检查非有限值及异常扩张，并渲染五种动作姿势。
3. `npm run build` 检查播放器和打包。

## 仍需精修

整体表面精修：使用局部保护蒙版和正负平滑交替，减少生成网格的碎小起伏，单点位移上限为 0.006 模型单位；五官、手爪和足底区域避免直接平滑。相同位移应用到全部已有形态键，保持眨眼相对位移；三角面数和 UV 不变。法线强度从原值降至 0.5，减轻贴图中的硬折痕。`render-pet-surface.py` 在同一灯光下输出修改前后正面、面部和背面对比。此步骤是表面精修，不是全身重拓扑，也不解决此前捂脸的大幅肩臂变形。

害羞节奏修正：取消整身压缩与侧倾，眼睑持续闭合量从 0.65 降至最多 0.12；改为低头避开、短暂停留、回看和回位。期间降低鼠标注视对头部的干预，避免与骨骼动作竞争。增加小幅 ShySmile 口部形态，不强行闭合原来的张嘴模型。该调整改善动作配合，仍不是完整眼球转动或嘴唇绑定。

挥手幅度调整：前臂和手掌旋转增至上一版的 1.7 倍，上臂保留受限参与。重新导入 GLB 后的采样最大手部位移由 0.0463 增至 0.0801，57,016 个保护区顶点的挥手位移仍为零。

挥手牵连修复：收紧手臂对躯干和脸部的权重范围，被移除的影响归还头部或躯干；Wave 仅保留左臂链，移除胸头动作，上臂摆幅降低，前臂和手掌承担挥动。`scripts/check-pet-wave.py` 对导出后重新导入的 GLB 采样，检查头、躯干、另一侧肢体与下肢保护区域不随挥手形变，同时确认手部仍有有效位移。

第三轮表情细节：新增 BlinkLeft、BlinkRight 和 Chew 三个可编辑形态键。左右眼闭合间隔 18 毫秒，使用快闭慢开的节奏，并低概率追加一次眨眼；咀嚼只在食物到嘴边后的时间段启用，嘴部最大位移约 0.00934 模型单位。`scripts/check-pet-face.py` 重新导入 GLB 检查位移范围并渲染睁眼、闭眼、咀嚼近景。闭眼边缘仍有原拓扑折痕，新形态键没有解决独立眼睑结构的问题。

第二轮步态修整：行走改为 60% 支撑相和 40% 摆动相，脚掌在支撑相保持水平，抬脚加入脚尖弧线。身体上下运动通过腿部反向位移补偿，并对重新导入的 GLB 检查支撑脚关节高度变化小于 0.001 模型单位。减速只改变动画采样进度，不再按速度缩小步幅；去除播放器额外的整身行走弹跳与倾斜。食物增加抬至嘴边、逐渐吃掉和消失的阶段。所有非行走曲线使用防过冲手柄，行走逐帧烘焙以保持支撑段的匀速后移。

这是一版可编辑的动画骨架和片段，不等同于完成专业角色重拓扑。面颊表面仍有生成模型起伏，嘴部没有独立口腔与下颌结构；Blink 仍是旧形态键。手脚目前采用柔和权重分配，尚未制作完整 IK、足底接触约束和关节修正形态。后续应在多角度动态审查基础上改进这些部位，不能用增加骨骼数量代替最终观感验收。
