# 日常工作区 UI 改版 · 实施记录

日期：2026-09-28

## 第二轮打磨（2026-09-29）

重新检查首屏、长清单和入口落点后，补齐日常操作中的细节：

- 今日清单直接输入并回车添加，只填标题时默认今天；日期、提醒等继续使用完整表单。按实际保存结果反馈，失败时保留内容并重试同一任务，不重复创建。
- 窄屏首屏显示“接下来”或“此刻安排”的日程入口，即使下方清单很长，也能看到最近时间安排；已过时间的待办不会误标为接下来。
- 侧栏收起偏好刷新后仍保留，仅保存本机布尔偏好；同步状态入口直达同步分区，设置关闭按钮补齐名称和触控尺寸，手机设置分类改为两行。
- 密码详情打开与返回时管理键盘焦点，返回账号列表立即隐藏密码与动态码。今日重点标识只匹配当前日期，避免沿用其他日期的标记。
- 删除空态中与快速添加重复的新增按钮，保留待安排入口。
- 计划中原“全部”实际只显示今天起的已排期任务，改名为“已排期”，并在空态提示去待安排整理；保留旧 URL 兼容。

新增日程选择规则测试；浏览器回归加入快速添加、连续两次模拟存储失败后重试不重复、刷新后唯一记录、手机首屏日程、密码返回焦点与显隐、设置落点及侧栏偏好恢复。

第二轮验证已通过：`npm run build`；`npm run test -- src/lib/__tests__/todaySchedule.test.ts src/lib/__tests__/attention.test.ts src/lib/__tests__/attentionJourney.test.ts`（3 个文件、20 项）；`node scripts/verify-ui-redesign.mjs`（含新增交互、55 次响应式检查、八种主题/风格截图与加密刷新恢复）。手机首屏见 `.visual-qa/ui-redesign/polish-today-mobile.png`。

基于 [案例研究](UI-REDESIGN-RESEARCH-2026-09-28.md) 和用户选择的“每天打开就清楚该做什么，任务和日历优先”落地。本次覆盖全局导航、今天首页、计划入口、专注/收集/回顾路径，以及密码库、资料库、Agent 资源库的信息层级。

## 设计如何落地

- 学习 Todoist 的“今天”入口：默认首页改成任务清单；完成任务折叠，当前待办与时间安排分开。
- 学习 Linear 的稳定导航：所有业务页使用同一侧栏，日历不再自动替换为另一套图标导航。按日常、内容、开发工具分组，工具组可折叠。
- 学习 Google Calendar 的时间画布：保留日历的周/月/日视图和内部导航，外部导航与其他页面一致；首页只显示当天时间摘要。
- 学习 1Password 的列表/详情：账号列表用于查找，当前账号详情用于查看、复制和编辑；切换账号收起已显示的密码及验证码。
- 说明和高级选项逐层展开：资料库说明、文件分类/正文提取、Agent 多维筛选默认收起；筛选生效条件可见。

具体案例来源与取舍见研究文档，不复制其他产品的色板。新增样式使用既有语义 Token，MASTER 已同步更新。

## 已实现

| 区域 | 行为 |
| --- | --- |
| 首页 | 今天、继续线索、今日重点/其他待办、折叠已完成、定时任务摘要、容量提示、逾期重新安排入口 |
| 日常流程 | 新建/编辑任务 → 开始专注 → 保存线索 → 返回原工作区；完成后写入回顾 |
| 原有线索 | 保留昨天收尾时留给今天的话；个人资料移至导航底部；弱密码提示移至密码库 |
| 桌面导航 | 232px / 中等窗口 208px，可收起为 72px；搜索、个人资料、设置、锁定固定可达；当前导航项自动滚入可见区 |
| 手机导航 | 今天 / 日历 / 收集箱 / 更多；更多复用现有弹窗焦点管理，其余模块从中进入 |
| 计划 | 视图与 URL 参数联动，可直接进入本周/待安排/全部等；开始专注后可回到原视图 |
| 收集箱 | 独立 `/collect`，复用灵感捕获、转待安排、留作便签、孵化架 |
| 回顾 | 独立 `/review`，包含完成记录、项目进展、一天收尾；兼容旧专注页面的分区链接 |
| 密码库 | 桌面列表/单项详情，窄屏点击进入详情并可返回列表；保留复制、TOTP、自动隐藏、编辑和删除 |
| 资料库 | 简化页头，说明折叠，文件名直接预览；保留缩略图网格、搜索、下载、编辑及批量管理；补上上传和预览的键盘可达性 |
| Agent 资源库 | 首屏保留搜索与收录入口，分类面板按需展开，显示已生效条件 |
| 共享视觉 | 页头与工具栏移除重复分隔线，统一间距、导航状态和移动端入口；沿用现有主题与壁纸能力 |

首页展示逻辑提取为 `useTodayWorkspace` 与 `TodayTaskList`；计划路由状态提取为 `usePlanView`；全局导航提取为 `AppNavigation`。

## 2026-09-29 截图反馈修订

- 根据用户澄清，日历恢复原有外框与圆角、面板间距恢复为 12px；仅将日历侧栏内部左右留白调整为 16px，避免文字贴边。
- 今天/本周共用稳定的页头布局，容量表单移入默认关闭的「安排设置」，每日节奏按需展开。
- 本周节奏横幅改成简短计数；日期仅突出选中项，移除非选中卡片边框、阴影及重复的空态提示。日期内容顶端对齐，保留留白日操作。
- 浏览器增加 390 / 1024 / 1440 宽度切换栏位置断言，以及安排设置开关和日历间距检查；截图为 `plan-week-refined-*`、`calendar-wallpaper`。
- 本轮修改的是源码与构建产物；此前已打开的 Windows 桌面进程不会自动加载本轮修改。
