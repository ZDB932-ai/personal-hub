# Personal Hub 1.2.0 · 集成预览版

本版将云账号、原生后台同步、桌面清单和界面优化合并为同一发布版本。Web、Windows、Android 均为 **1.2.0**，Android versionCode **16**。

## 本版内容

- 云账号：同一账号跨设备登录；支持改密、恢复密钥找回、加密记录与附件同步。
- Windows：独立桌面清单、托盘与桌面伙伴；清单支持置顶、折叠、位置保存和锁定显示配置。
- Android：可选及时后台同步、权限入口、状态诊断、串行原生任务及有界密文缓存。
- 外观：4 套既有设计加 10 套新增风格，共 14 套；覆盖导航、任务、日历、控件、表单与设置。
- 设置：分组导航、搜索直达、桌面双栏和手机分类详情；保留打开期间的表单草稿，关闭后清除敏感输入。
- 同步：暂停失败状态可见、保留并允许重试，防止较早的异步结果覆盖新会话。
- 手机计划页：修正风格按钮规则覆盖定位的问题，今天 / 本周切换时保留标签栏位置。
- 文档：更新 README、真实界面截图、下载链接、平台能力与恢复边界。

## 并行更新整合

整合前 GitHub main 与 v1.1.4 公开版较接近，本地已到 1.1.13，服务器部署为 1.1.8，Android 后台真机记录来自 1.1.12。2026-10-26 fetch 后未发现远端新增提交。对部署中的服务端文件逐一核对，运行逻辑与本地一致，差异仅为文本换行；本版保留既有服务端与数据库格式，更新客户端和发布资料。

1.1.12 后台修复保留在当前 Android 原生代码中，同时纳入 1.1.13 设置与风格优化。没有用较早的独立前端快照覆盖当前界面。

## 验证范围

- Node.js 24 环境下，52 个 Vitest 文件、315 项测试通过，包含服务端云账号、恢复与同步回归。
- 服务端类型检查、Web 生产构建通过；Windows NSIS 与 Android release 从同一 dist 构建。
- Android 7 项原生单元测试通过，166 个内嵌前端文件逐一校验一致，正式包签名与既有版本一致。
- 新版设置冒烟回归：5 组流程、259 项布局、103 组对比度检查通过，覆盖桌面与手机宽度、3 种代表风格及明暗模式。
- 核心 UI 回归通过：搜索与收集、任务与历史、密码恢复轮换、桌面伙伴、资料键盘操作、55 项响应式页面检查，以及 8 组明暗风格画面。
- 原有 1.1.13 广泛界面回归保留：14 套风格、桌面/平板/手机宽度、11 个页面，以及原生 Windows 设置入口验证。
- 本版发布文件附带 SHA256SUMS.txt 与 verification.json，记录 APK 签名、版本、内嵌前端文件校验及原生单元测试。

浏览器手机尺寸验证不等同于真机验收。既有 Android 1.1.12 在 PLB110 上通过 5/30/60/90/120 秒持续锁屏状态检查；这不是 1.2.0 的整夜后台测试。本次未覆盖安装到用户日常使用的 Windows/Android 数据目录。

## 更新方式

先在「设置 → 备份与迁移」导出加密备份。Android 使用同签名正式 APK 覆盖安装，保留现有数据；不要先卸载。Windows 安装新版后使用原账户解锁。跨设备请登录同一云账号。

服务器更新保留 /opt/personal-hub/data，先备份，再切换版本目录。旧版本目录保留用于回退；不会重新初始化用户账号或数据库。

## 已知边界

- 当前仍为个人使用预览版；没有团队协作或企业权限管理。
- Windows 安装程序未做 Authenticode 签名；其他桌面系统与 iOS 暂无原生包。
- Android 后台同步受系统省电、强行停止、网络与服务运行时限约束；没有永久常驻承诺。
- 本机账户恢复与云账号恢复是不同机制；恢复密钥不是数据备份。
- AI 工作台需自行配置兼容服务；第三方角色与素材权利见仓库 THIRD_PARTY_NOTICES.md。
