维修员诊断副本的接触相复测位于 `E:/Tripo pipline/assets/stellar-repairer/work/blender/pet-025/contact-regression.json`，脚本为同资产 `work/audit-pet025-contact.py`。独立 Blender 重新打开副本，核对源哈希与拓扑，使用旧冻结的左右脚区域及五段接触窗口，不保存模型。

原 Walk 在历史移动地面定义下最大水平漂移为 2.27715% 身高，修整后为 2.26816%；其他三段中部窗口完全相同，末段略有改善。最低脚部世界 Z 同为 0.00019998。静止地面下最大漂移仍为约 28.4% 身高，说明原地行走必须与窗口位移匹配。旧定义地面速度为每帧 0.027 源单位，24 fps 即 0.648 单位/秒；这不是已验收的桌面屏幕速度。

播放器现在提供可选 `groundSpeed`（导出模型世界单位/秒、1 倍速）和 `groundSpeedEvidence`。只有原地循环且校准字段完整的 walk/run 才能启用预设角色巡游，优先真实 walk，不用 run 名字冒充。校准数据必须来自同一实际导出及接触相证据，不自动给维修员草稿填写。

步频按实际逻辑像素速度、角色归一化尺度、正交相机可见高度和画布 CSS 高度计算；不重复乘设备像素比例。更新速度不会重启动作相位，零速停止步进，普通预览保持配置速度。屏幕左右巡游时角色转向，停止后回到手动朝向。奶龙保留旧步频路径。

新增单元测试覆盖校准缺失、walk-only、run-only、缩放与 CSS 像素换算、零速、相位连续和减少动态效果。尚未证明 Windows 实际窗口移动、斜向目的地视觉匹配、转向过渡或最终角色脚滑质量。本次不增加可用角色，也不把诊断副本当正式资产上架。
