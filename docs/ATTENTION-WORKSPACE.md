# 注意力工作区

## 五项体验扩展

- **任务现场书签**：专注页直接关联便签、资料和仓库，保存现场后优先出现在首页，手边资料保持展开。继续线索与引用均保存于原任务；不会自动打开外部程序或批量解密附件。重复任务下一次不继承现场标记。
- **空档菜单**：日历「当日安排」展开菜单，选择 15 / 30 / 60 分钟，最多出现三个候选。轻松模式明确指 15 分钟内任务，不推断用户情绪或任务难度。推荐仍需打开任务表单确认；休息按钮保护最近一段足够长的空档。既有任务和保护留白均参与避让。
- **灵感孵化架**：口袋条目可放入孵化架，使用「先放着 / 值得试试 / 正在推进 / 已归档」四个阶段。阶段保存在原便签，不复制正文。已有引用该便签的行动可直接继续；没有关联行动时可创建一个默认 15 分钟的待安排任务。归档保留内容，可以重新切换阶段。
- **项目故事线**：专注入口「项目故事」或日历方向卡片「回看项目故事」。按方向创建、任务创建、实际完成和关联便签创建时间排序；便签按 ID 去重，未收好的草稿不进入故事。资料从任务节点展开，缺失引用沿用原提示。本功能不是历史事件日志，编辑和移除原记录会改变故事内容。
- **一天收尾**：首页「收好今天」或专注入口「一天收尾」。展示当天实际完成记录，为明天留一句话，只有勾选的当天未完成任务才移动到次日，开始时间清空，容量提前提示。每日收尾复用同一便签；开场文字输入后自动加密保存，显式保存等待落盘。首页次日显示这句话，备忘录中可以编辑它。页面日期在进入时固定并明确展示，跨午夜需重新进入以收尾新的一天。

新增可选数据：Task.sceneSavedAt / sceneExpanded，Memo.ideaStage / closingDate / openingNote。沿用现有加密信封、同步、备份、锁定清理；验证入口检查日期、枚举和字段类型。

验收：`scripts/verify-attention-journey.mjs` 使用独立浏览器存储验证现场书签重载、灵感阶段、来源行动、空档预览和休息、选择性顺延、收尾重载、项目故事与次日首页提示，以及 320 / 375 / 768 / 1024 宽度。截图在 `.visual-qa/journey/`。

把已有任务、日历、备忘录和资料组织成一条连续路径：**选择一件事 → 专注推进 → 留下线索 → 收好灵感 → 回看成果**。

灵感来源是用户分享的 Jaden_riku 文章「注意力破产的人，再好的 AI 工具也救不了你」。原文链接：https://x.com/Jaden_riku/status/2039002380524736531 。本次据此设计注意力边界、输入暂存和成果回看；以下是产品设计延伸，不是文章原话。

## 页面结构

| 层级 | 入口 | 职责 |
| --- | --- | --- |
| 开始 | 总览「开始一件事 / 从这里继续」 | 优先呈现今日重点、最近继续线索；也可自行挑选 |
| 专注 | 导航「专注」、任务行播放图标、日历任务详情 | 只显示当前任务、继续线索、可展开的资料和灵感口袋；收起全局导航，保留返回与锁定 |
| 整理 | 专注 → 整理口袋 | 暂存灵感作为备忘录；选择转成待安排任务或留作便签 |
| 回看 | 专注 → 成果回廊 | 按实际完成周展示任务及关联进展便签、资料和仓库 |
| 安排 | 日历 → 当日安排 / 方向与足迹 | 保护具体留白时段，将暂时不做的方向放到下周再看 |

继续线索有两个字段：「做到哪里了」「下次回来，先做什么」。输入沿用加密数据库自动保存；暂停前显式等待持久化。灵感输入立即写入状态为 draft 的备忘录，随保险库加密保存；锁定统一等待保存，解锁后可继续。完成、暂停和页面手动锁定将其收入口袋；「放进口袋」等待保存回执，失败恢复同一草稿并允许重试。路由切换等待保存，刷新或关闭时仍有未落盘修改会触发浏览器离开提示。浏览器强制退出或设备掉电无法保证尚未完成的写入。

历史保护：继续线索的连续编辑在 5 分钟内合并，删除记录保留 200 条 / 2 MiB 额度，修改历史另有 100 条 / 1 MiB 的独立额度，每个条目最多 20 个修改版本；灵感草稿不产生逐次输入历史。

专注页没有计时惩罚、连续打卡或新增通知，也不屏蔽系统通知。任务完成继续使用既有确认弹窗，可以写进展便签和下一步；成果回廊引用真实完成记录，不虚构产出。

## 与既有数据的关系

- 继续线索放在 Task 的 `resumeNote / resumeNextStep / resumeUpdatedAt`；重复任务生成下一次时不继承旧线索。
- 灵感使用 Memo 的 `captureStatus` 标识草稿 / 待整理 / 已整理，`capturedFromTaskId` 留下产生时的任务引用。转任务保留原便签，通过 Task.links 建立来源关联；重复点击不重复创建。
- 留白存于 PlannerState.protectedTimes，使用日期与日内分钟区间。一天内相交区间取并集，从 09:00–18:00 的可排时段扣除一次，最终可用量取精力预算与可排时长的较小值；夜间留白不会额外扣白天预算。定时任务的负载按实际跨日区间分摊。排期建议避开区间，手工排期遇到重叠给出提示，已有任务不自动移动。跨午夜任务也检查次日留白；创建跨午夜留白需分两天添加。
- LongPlan.deferredUntil 在日期到达前过滤主动推荐和周计划自动安排，原有任务保留。用户可以「现在重新展开」，到期只恢复可推荐状态，不自动生成任务。
- 新字段都是可选项，沿用现有业务信封、备份与同步通道，没有新的明文业务存储。锁定时卸载业务页面并清空解密状态。

## 代码职责

`lib/attention.ts` 负责候选排序和时间区间运算；`stores/attention.ts` 负责收集、转任务、继续线索与留白操作。FocusView 只组织专注流程，FocusLaunch / InspirationPocket / FocusTrail 分别承担入口、暂存和成果回看。日历组件复用原有任务、容量与关联逻辑。

## 验证

`scripts/verify-attention.mjs` 使用隔离浏览器存储和合成数据，覆盖入口、继续线索、草稿收好、灵感转任务、保护留白与排期避让、暂缓方向、成果关联、锁定与加密重载。检查 320 / 375 / 768 / 1024 / 1440 宽度，截图输出到 `.visual-qa/attention/`。

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4188 --strictPort
node scripts/verify-attention.mjs
```

浏览器验收不替代 Windows 安装包、Android APK 的原生验收。本轮不新增 AI 或远程服务。

可靠性回归脚本 `scripts/verify-attention-reliability.mjs` 验证加密草稿刷新恢复、全局锁定恢复、模拟 IndexedDB 写入失败与无重复重试、继续线索搜索、来源回溯和完成后线索查看。截图位于 `.visual-qa/attention-reliability/`。
