## 1. 设计原则

本地账户入口：最大宽度 440px，桌面内部留白 32px、窄屏 24px/20px，沿用主题 surface/line/text 语义色。创建、保存恢复密钥、登录、恢复密码分步骤展示。密码控件至少 44px 高；账户名称明确为本机标识，清除数据不与找回密码合并。

### 日常工作区统一（2026-09-28）

用户已选择“每天打开就清楚该做什么，任务和日历优先”。首页使用今天、继续线索、今日清单、时间摘要四层结构；个人资料放到导航底部，收集箱与回顾为独立入口。桌面导航统一为日常/内容/开发工具，开发工具可折叠；默认宽 232px，中等屏幕 208px，可主动收起至 72px。日历沿用同一导航，不再自动切为专用图标栏。本节替代下方历史 56px 日历导航与 256px 普通导航规定。

今日任务允许紧凑列表与细分隔线，保留完成、标题和开始操作；继续线索采用单一 12px 基线卡片，元数据用 12px、正文 14px。容器仍使用语义 Token 与现有风格圆角变量。页头取消与紧邻工具栏重复的分隔线，分组通过留白区分。移动端导航为今天/日历/收集箱/更多，更多复用带键盘焦点管理的 ModalShell；日历、专注和所有辅助页面应维持清楚的返回路径。

专注为显式进入的任务模式，整理想法归收集箱，完成记录/项目进展/一天收尾归回顾。旧 `/focus?tab=...` 链接兼容至新入口；数据仍复用既有任务、便签和计划记录。

密码库采用账号列表与单项详情，1100px 以下在列表/详情间切换并提供返回操作；切换账号隐藏先前显示的秘密。资料库保留文件预览与下载，分类修改/正文提取收进「更多操作」。Agent 资源筛选默认收起，已选条件保持可见。操作说明默认折叠，空状态保留明确的创建入口。

2026-09-29 细化：今日清单支持单行快速添加，详细日期/提醒仍由完整表单承担，空态不重复提供同一新增按钮。1100px 以下在首屏以单行提示接下来/此刻的定时任务，具体日程仍位于时间摘要。已过时间的待办不标作“接下来”。桌面导航折叠状态为本机外观偏好；设置入口与打开分区一致，窄屏设置分类使用两行三列、44px 点击高度。密码详情返回列表时隐藏秘密并恢复原账号焦点。

### 外观工作室扩展

间距打磨补充：日历工具栏左右 12px、画布右侧和底部 8px 内部留白；不扩大面板外间距。工具栏搜索使用完整轻边框，避免输入下划线与工具栏分隔线叠加。密码字段行上下 12px 留白。窄屏任务标题与完成控件独占首行，元信息和操作在下行自然换行，禁止将任务标题挤到一两个字宽。

2026-09-29 截图反馈细化：计划视图切换栏紧随统一高度的页头，时间容量和每日节奏默认收进「安排设置」，不得在本周视图额外插入切换栏上方。周日期仅突出选中项，移除重复空态提示与非选中卡片边框。日历保留原有阅读衬底边框与圆角，桌面有壁纸时与主导航保持原有 12px 间隔；侧栏内部左右留白为 16px，保证文字不紧贴边框。

用户要求更大胆的视觉资源与背景能力。新增 `src/appearance-studio.css` 作为外观工作室规范：允许原创彩色艺术壁纸、16px 场景卡圆角、标题展示与独立预览；正文、卡片和功能信息继续使用语义 Token。新增强调色 coral（珊瑚）、cobalt（钴蓝）、orchid（兰紫），各含独立明暗 Token。壁纸仅在解锁区域显示，允许 0–16px 图片柔化，不对业务内容使用模糊。阅读衬底使用 94% body 基座，背景遮罩可自动适配明暗或手动调节。原版平面限制不适用于用户选择的艺术资源。

场景一次应用风格、明暗、色调、壁纸及推荐构图，提供会话内撤销。外观入口统一为「整套搭配 / 界面样式 / 背景设置」，采用等宽分段按钮与职责说明。常规风格选择保留配色、明暗和背景。禁止在业务组件散布装饰颜色。新图原件保存在 assets/wallpaper-originals，发布 JPEG 和独立缩略图位于 public/wallpapers。

### 可选界面风格（2026-09-20）

用户要求提供多套可切换 UI。下文原有平面、颜色、圆角与阴影限制保留为 `classic` 默认风格；新增风格仅通过 `src/interface-styles.css` 的语义 Token 和 `html[data-interface]` 定义例外，业务组件不得自行硬编码颜色。所有风格支持 light/dark，与六种强调色、壁纸独立组合。单独选择风格保留当前强调色、明暗模式和壁纸；只有整套搭配同时更新这些设置。

| 风格 | 基座与构图 | 圆角 / 层次 |
| --- | --- | --- |
| classic 经典纸感 | 原版暖白，青碧推荐色 | 控件 8px / 卡片 12px，原有平面规范 |
| sunrise 晨光工作室 | 奶油暖色、宋体展示标题、暖色侧栏，琥珀推荐色 | 控件 12px / 卡片 16px，轻微暖色投影 |
| aurora 极光浮岛 | 冷色柔光背景、悬浮侧栏、独立页头、实色选中导航，靛蓝推荐色 | 控件 14px / 卡片 20px，柔和投影；背景允许两处静态径向渐变，不使用模糊 |
| precision 精密面板 | 蓝灰线框、分区标线、紧凑卡片间距，湛蓝推荐色 | 控件 4px / 卡片 6px，零投影；保留操作触控尺寸 |

风格仅调整展示，不改变业务数据与操作流程。预览通过 `--preview-*` Token 表达各套风格并跟随当前明暗模式。偏好保存在 `xk.theme.v1.style`；缺失、未知值回退 classic。首屏同步应用 data-interface，避免刷新后先显示另一套风格。分类和状态颜色保持原有语义，正文不可为了风格降低可读性。

1. **平面优先**：无渐变、无毛玻璃（backdrop-blur）、无彩色光晕；层次只靠「明度差 + 1px 边框」
2. **单一强调色**：全站唯一品牌色 teal；彩色只允许出现在语义功能上（成功/警告/危险/分类标识）
3. **内容即界面**：装饰性元素为零；留白与字重承担层级
4. **动效克制**：150–200ms 标准过渡；列表入场 300–450ms；`prefers-reduced-motion` 时全部动画降为瞬时
5. **浅色优先**：暖白纸感基座，墨绿灰文字与低饱和青绿交互；深色是等价的可选外观，不是亮色反相

### 2.1 色彩（亮色 · 默认）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-body` | `#F7F6F2` | 页面背景 |

| `--color-primary` | `#427D72` | 品牌色：主按钮、激活态、链接、焦点环 |
| `--color-primary-strong` | `#326C63` | 主按钮悬停 |

| foreground | `#202925` | 正文 |
| muted | `#62706A` | 次要文字的**下限**，禁止更浅的灰正文 |
| success | 深绿语义色 | 完成、正常态 |
| warning | 暖褐语义色 | 逾期、提醒 |
| danger | 豆沙红语义色 | 删除、错误、弱密码 |
| 分类色板 | 低饱和 sky/emerald/amber/rose/fuchsia/cyan（浅底 + 细边 + 深色文字） | 仅用于分类徽章，不作装饰 |

规则：
- 正文对比度 ≥ 4.5:1；元数据使用语义 `text-t3/text-t4`，禁止原始 slate 调色
- 主按钮：`bg-primary text-ink hover:bg-primary-strong`，**禁用渐变与投影**
- 危险操作：rose 边框 + 10% 底，不用填充按钮

### 2.3 主题系统（运行时切换）

两层维度，用户可在「设置 → 外观」自由组合，偏好存于 `xk.theme.v1`：

| 维度 | 取值 | 切换机制 |
| --- | --- | --- |
| 外观模式 | `dark` / `light` / `system` | `<html data-theme>`；system 监听 `prefers-color-scheme` |
| 主题色调 | `teal` / `indigo` / `blue` / `violet` / `rose` / `amber` | `<html data-accent>` |

- Token 链：`@theme inline` 把 `--color-*` 映射到 `--tk-*` 运行时变量；工具类（含 `/透明度`）经 `color-mix` 即时解析，切换零重渲染
- 亮色为默认基线（见 §2.1）；深色 Token 需独立校对表面、线条与文字对比度，不可机械反相
- 2026-09-20 可读性更新：辅助文字 t4 的对比度与 t3 对齐，以字号和位置区分层级；深色六款强调色使用独立浅色 Token，按钮前景 ink 使用深色，避免复用亮色强调色导致链接不可读。数值统一定义在 `src/style.css`。
- 每个色调预设三件套：`primary / primary-strong / ink(on-primary)`，teal 与 amber 用深色 ink，其余用白色
- 分类徽章与便签色板走语义类（`.badge-*` / `.memo-*`），CSS 内含双主题色值；**禁止**在组件里写死分类颜色

- 分类徽章与便签色板走语义类（`.badge-*` / `.memo-*`），CSS 内含双主题色值；**禁止**在组件里写死分类颜色

### 2.7 背景图片（可选层）

- 层级：壁纸图（fixed, z-0）→ 主题色暗度遮罩（`color-mix(var(--tk-body), X%)`）→ 内容（z-10，卡片保持不透明）
- 内置 6 款程序化抽象壁纸（`public/wallpapers/w1~w6.jpg`，约 38KB/张）；自定义图片存本机 IndexedDB `xk-wallpaper`（≤8MB，不参与云同步）
- 可读性：默认暗度 65%，可调 0–85%；建议 ≥50%。文字对比度由遮罩保证，卡片内容永不受壁纸干扰
- 锁屏页不使用壁纸（隐私优先）

### 2.4 间距与圆角

- 间距：4px 基数（1=4 / 2=8 / 3=12 / 4=16 / 6=24 / 8=32）；卡片内边距 20px（p-5）
- 圆角：卡片/弹窗 `rounded-xl`(12px)；按钮/输入框/徽章 `rounded-lg`(8px)；头像/图标座 `rounded-full/xl`
- **禁用** rounded-2xl 及以上

### 2.5 阴影与高度

唯一允许的投影：弹窗层 `shadow-2xl shadow-black/50`。其余元素零阴影，层次靠 surface 明度。

### 2.6 动效

| 场景 | 规格 |
| --- | --- |
| 悬停/状态 | 150–200ms ease（颜色/边框/明度，禁止位移缩放类大动效） |
| 路由切换 | 淡入 + 6px 上移，180ms |
| 弹窗 | 淡入 + 12px 上移，200ms |
| 列表入场 | 300–450ms，每项 stagger 60ms（暂以 CSS transition 实现，不引 GSAP） |
| 骨架屏 | 1.4s 扫光循环（`.skeleton`） |
| reduced-motion | 全部动画/过渡 ≤ 0.01ms |

## 4. 布局

### 日历工作台（2026-09-25）

参考用户提供的 Google 日历截图，日历页采用独立的全高工作区：全局导航为 56px 图标栏，日历侧栏 208px，画布扩展到可用宽度。允许日历画布 24px、创建按钮与侧面板 16px、工具栏分段与「今天」按钮胶囊圆角；这些例外只用于日历，不改变其他页面。默认只显示主画布与迷你月历，详情和便签按需展开。日期表头使用 44px 圆形高亮「今天」，农历来自本地 Intl 中国历法；当前时间用 danger 语义线，便签来源任务用 info 色与链接图标标识。网格线用 line Token 的 60–75% 混色，浮层保持实色。小时格支持半小时创建，短任务在详情提供完整操作入口。迷你月历是高密度日期导航，允许 32px 日期格，并提供方向键／Home／End／Page Up／Page Down 导航。

日历的月网格和周／日小时网格允许共享日期边线，用于表达时间坐标；其他重复内容仍使用独立卡片。日历继续使用 surface/line/primary/t1–t4 语义 Token，重叠任务分列；手机默认日视图，周视图只在时间面板内部横向滚动。便签架及留白窗口采用既有 12px 圆角卡片。时间轴每小时 96px，定时任务卡片最小高度 44px，使用 8px 圆角、左侧语义色细边、标题与真实时间两层排版。短任务的显示高度不代表延长时长，显示分列按实际卡片边界避让，空档与冲突仍按真实时间计算。接近午夜的短卡片允许延伸到时间轴底部留白区。已完成任务只划掉标题，保留清晰时间；当前时间线从卡片下方通过，避免划过文字。

- 桌面：左侧固定导航 256px；内容区 `max-w-7xl` 居中，内边距 24/40px
- 移动（<768px）：顶部条 + 底部 Tab（6 项，安全区 padding）；内容区底部预留 Tab 高度
- 断点：375 / 768 / 1024 / 1440；卡片网格 1→2→3 列
- 弹窗：移动端全宽 -32px 边距，最大高 85vh 内滚动

## 5. UX 准则与反模式（检索自 ux-guidelines，按严重度）

### 注意力工作区（2026-09-27）

五项体验扩展继续在原有入口内渐进展开：现场书签位于继续线索后；空档菜单收进日历当日安排；孵化架沿用便签卡片和四阶段筛选；项目故事使用独立时间节点卡片；收尾以完成记录、次日一句话、自选顺延组成。专注页导航允许换行，手机不依赖整页横向滚动。新表单复用 AppSelect 与语义控件；所有写入成功反馈等待持久化回执。

结构分为总览开始入口、当前任务专注页、整理口袋与成果回廊。当前任务页收起全局导航，保留返回和锁定；主栏呈现任务与继续线索，288px 次栏用于暂存灵感，900px 以下顺序堆叠。背景、卡片、输入框沿用语义 Token 和 12px / 8px 圆角；不添加投影、渐变或新色板。主标题 24–36px，信息按任务、继续线索、可展开的资料、操作排列。成果与候选任务使用独立卡片。留白在时间轴以弱底色与虚线边界呈现，不伪装成待完成任务。详见 `docs/ATTENTION-WORKSPACE.md`。

**必须（CRITICAL/HIGH）**
- 对比度 4.5:1；键盘可达；焦点环可见（primary 色）
- 触控目标 ≥ 44×44；加载反馈匹配预期等待时长（瞬时操作不显示 loading）
- 表单：label 可见、错误就近展示、必填标注
- 通知/删除等破坏性操作需确认
- 图标用 SVG（lucide），禁止 emoji 当图标

**避免（Anti-patterns）**
- 灰上灰文字、占位符当 label、错误只在表单顶部
- 仅 hover 才能发现的操作（移动端无 hover）→ 主要操作必须常显
- 0ms 瞬变与 >500ms 拖沓动效并存；宽度/高度动画
- 渐变、玻璃模糊、彩色光晕（本系统明确弃用）
- 复杂引导流程、首屏性能债
